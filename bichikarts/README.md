# Bichikarts — prototipo 2D (solo referencia)

Esta carpeta es un **primer intento en 2D** que quedó **incompleto** y **no es el juego**.
El juego se va a hacer en **3D**; esto se guarda solo como referencia de ideas.

Qué hay adentro, por si sirve:

- `Assets/Bichikarts/Scripts/Core/`: reglas en C# puro (agarrar la comida, aguantar, robar, reiniciar el tiempo,
  gravedad por karting, tuberías) y una compu que juega probando maniobras en una simulación chiquita.
- `Assets/Bichikarts/Scripts/Game/`: dibujos hechos por código (bichitos, karting, comida, salas) y menús.
- `CoreTests/`: pruebas de las reglas (`dotnet test`).

Le faltan archivos para abrirse como proyecto de Unity (por ejemplo `Packages/manifest.json`).
