## Asesor forense para guion

[`.claude/skills/forense-cine`](.claude/skills/forense-cine/) es un skill de Claude Code que convierte a Claude en consultor forense de una película: diseña pistas fuera de lo común pero científicamente plausibles, revisa escenas del guion y mantiene la coherencia de la investigación en `pelicula/biblia-forense.md`. Se carga solo en cualquier sesión de Claude Code abierta en este repositorio.
